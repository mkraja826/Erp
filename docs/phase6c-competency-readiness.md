# Phase 6C — Competency Scoring + Workplace Readiness

The learner skills profile is the single aggregation point for ERP Edu competency evidence.

It combines:
- course completion
- transaction accuracy from completed training sessions
- training independence from Guided / Assisted / Workplace evidence
- Work Lab practical execution
- Incident Lab investigation performance
- job-readiness assessment results

Every recalculation updates one deterministic learner-owned `COMPETENCY_PROFILE` ERP document. This prevents isolated score fragments and provides a durable readiness snapshot for later workplace queues, employer views, certification, and progression logic.

Readiness bands are: foundation, developing, applied, workplace_ready, certified.
